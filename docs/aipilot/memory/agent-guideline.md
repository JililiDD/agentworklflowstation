# Agent Guidelines

## Active Workflow Overrides

### 项目文档使用简体中文

- **Added:** 2026-10-13
- **Scope:** 文档根目录下的所有项目文档，包括 spec、work-item、计划、memory 和 `CHANGELOG.md`。
- **Rule:**
  - 用简体中文写项目文档的正文。这条规则覆盖宪法 §7 的英文默认规则。
  - 模板或 skill 定义的标题和字段标签保持英文。例如 `## Requirement`、`Done when:`、`— Verify:`、`User Story 1:`、`Task 1.1:`。审阅页面和各 skill 靠这些英文标记定位内容。
  - ID 保持原样，例如 `AC-n`、`D-n`、`A-n`、`Q-n`。
  - 代码、命令、文件路径、标识符和 YAML 字段名保持原样。
  - 继续使用压缩版 ASD-STE100 写作规则。步骤句最多 40 个汉字，描述句最多 50 个汉字。
  - 验收标准使用中文 EARS 句式：「当<触发>时，系统应<结果>。」「在<状态>期间，系统应<结果>。」「如果<异常事件>，那么系统应<结果>。」「系统应<结果>。」
- **Supersedes:** 无
